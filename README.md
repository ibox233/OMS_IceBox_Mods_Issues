## 中文

欢迎来到 IceBox 的 《菜市场模拟器》 系列模组的问题反馈与建议收集仓库！

本仓库是以下七个模组的**官方反馈通道**：

### 支持的模组

#### BetterMarketPlus
- **功能描述**：修复原始 BetterMarket 模组因游戏版本更新导致的问题和错误，并在调整和增强原有游戏体验的同时，增加了更多新内容和功能

#### BuyMoreFixed
- **功能描述**：解锁每日码头订购上限的重写修复版本

#### AutoRestockFishFixed
- **功能描述**：自动从地窖中补充鱼的重写修复版本

#### DropAllStack
- **功能描述**：按住快捷键可一键堆叠/丢弃背包中相同物品

#### InventorySelectionHighlight
- **功能描述**：自定义物品栏选中高亮颜色和粗细

#### FruitTreeIgnoreSeason
- **功能描述**：让果树忽略季节进行生长和结果

#### WorkshopNoSpoil
- **功能描述**：工作坊可以和地窖一样存放物品，不会让物品腐坏

### 如何报告问题

在提交问题前，请确保：

1. **搜索现有问题**：检查是否已有相同或类似的问题报告
2. **确认模组版本**：请在问题中注明具体的模组版本号
3. **提供详细信息**：包括游戏版本、其他模组列表、错误日志等

## English

Welcome to the IceBox's Old Market Simulator mod series issue feedback and suggestion collection repository!

This repository is the **official feedback channel** for the following seven mods:

### Supported Mods

#### BetterMarketPlus
- **Description**: Fixes issues and bugs in the original BetterMarket mod caused by game version updates, while adjusting and enhancing the original game experience with more new content and features

#### BuyMoreFixed
- **Description**: Rewritten and fixed version that unlocks the daily dock ordering limit

#### AutoRestockFishFixed
- **Description**: Rewritten and fixed version that automatically restocks fish from the cellar

#### DropAllStack
- **Description**: Hold down the hotkey to stack/drop identical items in your inventory with one click

#### InventorySelectionHighlight
- **Description**: Customize inventory selection highlight color and thickness

#### FruitTreeIgnoreSeason
- **Description**: Allows fruit trees to grow and bear fruit regardless of season

#### WorkshopNoSpoil
- **Description**: Workshops can store items just like cellars, preventing items from spoiling

### How to Report Issues

Before submitting an issue, please ensure:

1. **Search Existing Issues**: Check if there are already the same or similar issue reports
2. **Confirm Mod Version**: Please specify the exact mod version number in the issue
3. **Provide Detailed Information**: Include game version, other mod lists, error logs, etc.
